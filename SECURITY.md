# Security policy

## Reporting a vulnerability

Please report security problems privately through this repository's **Security** tab ("Report a vulnerability"). Do not open a public issue or pull request for anything exploitable.

Include what you found, how to reproduce it, and what you think the impact is. You can expect an acknowledgement within a few days.

## Scope

In scope: the Python package, the dashboard, the Dockerfile and compose file, and the CI workflows in this repository.

Out of scope: the third-party job boards the tool reads from, and any deployment of this code that isn't the maintainer's own.

## If you find a secret or personal data in the repo

Report it privately as above, even if it looks old or already removed. Please don't copy it elsewhere.
